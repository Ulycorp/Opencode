# Marketing

- `persona/` contient les sources et le persona opérationnel.
- `strategy/` contient positionnement, offres et plans de campagne.
- `creatives/briefs/` contient les briefs.
- `creatives/generated/` contient les assets non versionnés par défaut.
- `creatives/metadata/` contient une metadata versionnée par asset.
- `seo-geo/` contient les adaptations marketing SEO/GEO.
